# java-lotto-precourse

#  기능 요구사항 정리

간단한 로또 발매기를 구현한다.

## 1. 요구 기능 정리

1. **로또 발행 기능**
    - 구입 금액에 따라 로또를 발행한다. (1장 = 1,000원)
    - 각 로또는 1~45 사이의 **중복되지 않는 6개의 숫자**로 구성된다.
    - 발행된 로또 번호는 **오름차순으로 정렬**된다.

2. **입력 검증 기능**
    - 구입 금액은 **1,000원 단위의 양의 정수**여야 한다.
    - 당첨 번호는 쉼표(,)로 구분된 6개의 숫자이며, 중복 없이 1~45 범위 내에 있어야 한다.
    - 보너스 번호는 1~45 범위 내의 숫자이며, 당첨 번호와 중복될 수 없다.

3. **당첨 결과 계산 기능**
    - 구매한 모든 로또를 당첨 번호와 비교하여 일치 개수를 계산한다.
    - 5개 + 보너스, 6개 일치 등 기준에 따라 **1등~5등 등수 및 상금**을 판단한다.
    - 등수별 당첨 횟수를 집계한다.

4. **수익률 계산 기능**
    - 총 당첨금 / 구매금액 × 100 (%) 계산
    - 소수점 둘째 자리에서 반올림한다. (예: `62.5%`)

5. **출력 기능**
    - 구매한 로또 수량 및 각 로또 번호를 출력한다.
    - 당첨 내역과 등수별 개수를 출력한다.
    - 총 수익률을 출력한다.

6. **예외 처리**
    - 잘못된 입력 시 `IllegalArgumentException`을 발생시키고 `[ERROR]`로 시작하는 에러 메시지를 출력한다.
    - 해당 입력부터 다시 받는다.
    - `IllegalStateException` 등 명확한 예외 유형만 사용한다.

## 2. 세부 기능 목록

| 구분 | 기능 설명 | 입력 예시 | 출력/결과 예시 |
|------|------------|------------|----------------|
| 구입 금액 입력 | 1,000원 단위로 입력 받음, 검증 수행 | `14000` | ✅ 통과 |
| 당첨 번호 입력 | 쉼표(,)로 구분된 6개의 숫자, 중복 불가 | `1,2,3,4,5,6` | ✅ 통과 |
| 보너스 번호 입력 | 1~45 사이, 당첨 번호와 중복 불가 | `7` | ✅ 통과 |
| 로또 발행 | 입력 금액 기준으로 N장 발행 | `14000` → 14장 | `[1, 3, 8, 22, 35, 41]` |
| 일치 개수 계산 | 구매 로또와 당첨 번호 비교 | `[1,2,3,4,5,6]` | 6개 일치 → 1등 |
| 등수 판별 | 일치 수 및 보너스 포함 여부로 등수 결정 | 5개+보너스 | 2등 |
| 수익률 계산 | (당첨금 합계 ÷ 구입금액) × 100 | 당첨금 87500, 구입금 14000 | `62.5%` |
| 출력 | 로또 목록, 당첨 내역, 수익률 출력 |  | 콘솔 출력 |

## 3. 클래스 계층 구조

```plaintext
src/
 ├── controller/
 │    └── LottoController.java        # 게임 전체 흐름 제어 (입력 → 발행 → 비교 → 출력)
 │
 ├── domain/
 │    ├── Lotto.java                  # 로또 1장의 번호 관리 (중복 불가, 정렬)
 │    ├── Lottos.java                 # 여러 장의 로또 관리
 │    ├── LottoGenerator.java         # 랜덤 로또 번호 생성
 │    ├── WinningNumbers.java         # 당첨 번호 + 보너스 번호 관리
 │    ├── Rank.java                   # 당첨 등수 및 상금 기준 Enum
 │    ├── WinningResult.java          # 등수별 당첨 결과 집계
 │    ├── ProfitCalculator.java       # 수익률 계산
 │    └── InputValidator.java         # 입력값 검증 (금액, 번호, 보너스)
 │
 ├── view/
 │    ├── InputView.java              # 사용자 입력 (금액, 번호)
 │    └── OutputView.java             # 결과 출력 (로또 목록, 당첨 내역, 수익률)
 │
 └── Application.java                 # 프로그램 진입점 (main)
